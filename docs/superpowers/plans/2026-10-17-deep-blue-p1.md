# Deep Blue P1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans for inline implementation, or superpowers:subagent-driven-development if the user selects delegation. Steps use checkbox syntax for tracking.

**Goal:** 交付可进入、拆解、返回和无漂移复位的 Deep Blue 低精度三维原型。

**Architecture:** 保留 P0 审阅站，在 /prototype/ 新增本地打包入口。纯状态/姿态模块驱动 Three.js 模型、相机及 DOM，几何检验与浏览器视觉检查互补。

**Tech Stack:** Node >=22、JavaScript ESM、Three.js、esbuild、Node 内置 test。

**Spec:** ../specs/2026-10-17-deep-blue-p1-design.md（用户已于 2026-10-17 确认）。

## Global Constraints

- 仅修改 deep-blue-studio；不自动推送、部署或进入 P2，不自动提交产品代码。
- 2 柜、30 节点、1 CPU/节点、2 卡/节点、8 芯片/卡，逻辑总计 480；每柜 15 节点仅为教学布局。
- +Y 向上、+Z 向前、+X 向右；display-unit，不宣称实测尺寸。
- 界面持续标注“教学重建，非实测尺寸”；芯片层标注“放大功能示意，非实际版图”。
- 原有 P0 根入口、资料、validate 与 build-review 保留；不改变 D01–D05 用户审阅状态。
- 姿态由初始值和绝对进度推导；只有一个动画循环；reduced-motion 与普通模式同终点。

## Review Focus

1. 动画期间重复点击与反向：最新目标生效，不能积压旧动作（任务 1）。
2. 后台停留后恢复：进度不因长时间差瞬间跃迁（任务 1、3）。
3. 窄屏、键盘及自由观察后切站：按钮可达、说明一致、镜头重新聚焦（任务 3、4）。
4. WebGL 初始化失败：给出可理解提示及 P0 返回入口（任务 3）。
5. 缺少前置构建或静态路径错误：不能返回空白页或泄露仓库文件（任务 3、4）。

所有新行为测试先运行并记录预期失败，再实现并运行通过。下述路径均相对于 deep-blue-studio。

## Task 1 · 可逆运动和状态

**Files:** 新增 src/prototype/motion.js、src/prototype/state.js、tests/motion.test.mjs、tests/state.test.mjs；修改 package.json（test 脚本）。

**Interfaces:**
- motion.js：STATIONS = [0,3,5,6]；samplePose(progress:number):Pose，进度钳制为 0..6；Pose 包含 doorAngle、disconnected、nodeZ、coverY、coverX、cardY、cardAngle、microVisible。每段分别对应开门、断连、节点、盖板、板卡、芯片；板卡段先拔出后转向。
- state.js：createState({reducedMotion=false}={}):{progress,target,station,reducedMotion}；selectStation(state,index):state、advance(state,deltaSeconds):state、resetState(state):state，均返回新状态。advance 限制单次时间差至 0.05 秒；常速 1 段/秒。

- [ ] 写失败测试：samplePose(0) 为初态；progress<=1 时 nodeZ=0，progress<=3 时 coverY=0，progress<=4 时 cardY=0；板卡段前半程 cardAngle=0；microVisible 仅在最后芯片阶段出现。
- [ ] 写失败测试：0→6 中途反向后单调回退；连续选择目标只保留最新站点；100 次往返后 resetState 与初态深相等；reduced-motion 直接到达目标；advance(s,120) 与 advance(s,0.05) 相等。
- [ ] 运行 `node --test tests/motion.test.mjs tests/state.test.mjs`，确认失败是接口/行为未实现。
- [ ] 实现上述接口，将运动距离集中为常量供模型与几何检查复用；站点索引越界钳制；非有限进度与 delta 安全回退，不生成 NaN。
- [ ] 重跑同一命令通过；补入非有限输入断言后再次通过。记录该任务完成状态，不自动提交。

## Task 2 · 实体模型与空间校验

**Files:** 新增 src/prototype/model.js、src/prototype/geometry-checks.js、tests/model.test.mjs；新增 package-lock.json；修改 package.json（three、esbuild 依赖）。

**Interfaces:**
- createModel(contract):{root,parts,applyPose(pose),dispose()}；parts 包含 door、node、cover、cards、chips、cpu、micro；原始姿态保存且不因 applyPose 变化。模型直接使用任务 1 的 Pose。
- checkClearance(model,progress):Array<{pair:string,penetration:number}>，通过世界坐标包围盒对指定实体对检测；报告超出 1e-6 容差的穿透，不忽略全部接触。

- [ ] 安装 three 及 esbuild 并锁定依赖；写失败测试：实例中 30 节点、选中节点 1 CPU/2 卡/16 芯片；micro 与实物场景分组，逻辑总量=480。
- [ ] 写失败测试：采样 0..6，步长 0.02，门/节点通道、盖板/PCB、两卡之间无非法穿透；将节点故意移入另一张卡，断言检测报告违规，证明检查器有效。
- [ ] 运行 `node --test tests/model.test.mjs`，确认未实现导致失败。
- [ ] 实现低模与检查器。节点从柜内同一对象抽出；门向外开；盖板抬升后侧移；卡拔出后转向；必要时调整并记录草图比例。允许的原位装配接触按具体实体对与阶段声明，不能靠全局关闭检测通过。
- [ ] 测试增加 applyPose 同一进度两次幂等、往返后对象矩阵与基线差<=1e-6、dispose 后几何/材质去重释放；运行全部 Node 测试通过。

## Task 3 · 可操作浏览器入口

**Files:** 新增 src/prototype/scene.js、src/prototype/main.js、prototype/index.html、prototype/style.css、scripts/build-prototype.mjs、tests/server.test.mjs；修改 scripts/serve.mjs、package.json、review/index.html。

**Interfaces:**
- createScene(canvas,model):{render(state),focus(station,view),resize(),dispose()}；view 为 perspective/front/side/top；相机与 Pose 共同读取进度。
- main.js 组合状态、模型、场景与原生按钮；优先从本地打包导入 MODEL_CONTRACT，不发起 CDN 请求。
- build 输出 review/prototype/app.js 及该入口 HTML/CSS；构建产物按现有 .gitignore 约定排除；serve 仍仅暴露 review 根目录、监听 127.0.0.1:4175。

- [ ] 写 server 集成失败测试：根页可访问、/prototype/ 返回 HTML、bundle/CSS 返回正确 MIME；点路径和编码越界请求被拒绝；不存在文件返回 404。测试使用独立临时端口，不能停止用户现有 4175 服务。
- [ ] 运行测试，确认原型路径未实现而失败。
- [ ] 实现构建与页面：炭黑舞台、暖纸说明、蓝色选中；四站点、前后步、复位、正侧顶视按钮；OrbitControls 限制缩放范围；站点变化重聚焦。标记教学边界，回链 P0。
- [ ] 实现 WebGL 错误提示；单一 rAF；visibilitychange 暂停并清除旧时间戳；matchMedia reduced-motion 动态响应；ResizeObserver；卸载移除监听器、释放场景和控件。按钮提供禁用边界与 aria-live 当前站点。
- [ ] 执行 build、全部 Node 测试、既有 validate，均通过；检查 prototype/index.html 不引用外部运行时代码。
