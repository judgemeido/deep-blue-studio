# Deep Blue P3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement task-by-task in the current session. Steps use checkbox syntax for tracking.

**Goal:** 在现有展品内提供可复现的搜索、剪枝比较、任务分配及五步教学闭环。

**Architecture:** 纯搜索模块生成事件日志，纯回放状态消费日志，原生 DOM/SVG 展示状态。教学控制器仅调用既有三维站点命令，并复用 main.js 的唯一动画循环；默认自由观察与已认可的动画保留。

**Tech Stack:** 现有 JavaScript ESM、Node test、DOM/SVG、Three.js、esbuild；不新增依赖。

**Spec:** ../specs/2026-10-17-deep-blue-p3-design.md（用户已确认）。

## Global Constraints

- 仅修改 deep-blue-studio，不重做已认可的板卡朝向、芯片放大与灯光；不自动提交、推送或部署。
- 五步：接到棋局 → 展开搜索 → 理解剪枝 → 分派计算 → 进入芯片。
- 同一 15 节点、8 叶三层二叉教学树；两算法共用输入和着法顺序，平分取第一个根子节点。
- 访问次数与叶评估次数必须来自真实运行日志；剪枝条件 alpha>=beta。
- 调度演示明确为逻辑时间，不展示虚构实测加速；历史 30 节点/480 芯片与虚拟 1/4/8 工作者分开。
- 不新增 rAF；后台暂停且不补播；减少动态效果关闭自动播放，保留单步。
- 现有 P1/P2 未验收项继续保留，不将本轮视作自动补齐。

## Review Focus

1. 自动播放时切算法、换顺序或重来：旧日志不得继续推进（任务 2）。
2. 后台恢复与减少动态偏好改变：不得补播、突然完成或继续自动动画（任务 2/3）。
3. alpha-beta 剪枝后：未访问节点不能标为已评估；剪枝原因须使用当时界限（任务 1/3）。
4. 8 个工作者只有 2 个根任务：明确显示 6 个空闲，不制造额外任务（任务 1/3）。
5. 退出教学和再次进入：停止播放、恢复可用自由操作，无重复监听器（任务 3/4）。

新增 src/teaching/search.js（输入树、算法及事件）、scheduler.js（纯任务分配）、playback.js（纯回放状态）、teaching-ui.js（DOM/SVG 控制器）、tests/search.test.mjs、scheduler.test.mjs、playback.test.mjs、docs/P3_ACCEPTANCE.md。修改 src/prototype/main.js（桥接与唯一循环）、prototype/index.html、prototype/style.css（模式入口与教学容器）、README.md、package.json/lock（阶段版本）。不改变模型模块职责。

## Task 1 · 搜索结果、事件及任务分配

**Interfaces:**
- makeTeachingTree({reverse=false}={}):Node；Node 为 {id,children} 或 {id,value}，id 稳定且唯一。
- runSearch(tree,{strategy='minimax'}={}):{value,bestChildId,events,visitedNodes,evaluatedLeaves}。events 为顺序不可变记录，类型 enter/evaluate/return/bound/prune；含 nodeId，剪枝含 skippedIds、alpha、beta、reason。每次递归分支交替 MAX/MIN。
- scheduleTasks(tasks,workers):{assignments,idleWorkers,makespan}；任务 {id,cost}，cost 为单独 minimax 根子树 visitedNodes；按最早空闲工作者分配，平分取编号较小者，记录 start/end。workers 只允许 1/4/8。

- [ ] 写失败测试：固定叶分数 [3,5,6,9,1,2,0,-1]，手算根值 5、最佳根子节点左；两策略结果一致；叶评估 minimax=8，alpha-beta<=8，访问数等于 enter 数、评估数等于 evaluate 数。
- [ ] 运行 `node --test tests/search.test.mjs`，确认因接口/功能缺失失败。
- [ ] 实现输入、纯算法与事件；不靠显示层推测剪枝，prune 在当时 alpha>=beta 时产生，skippedIds 列出未进入分支后代。反序保持 id 与评分，仅反转 children。
- [ ] 测试平分选择首个、全负值、反序树、100 棵种子生成树两算法结果一致；拒绝空 children、重复 id、NaN 分值、未知策略；确认无输入变异。运行测试通过。
- [ ] 写调度失败测试：cost 为 7、7，1 工作者 makespan=14，4/8 工作者 makespan=7，idle=2/6；每任务恰好分配一次，同工作者无时间重叠；拒绝重复任务 id、非正 cost、非法 workers。
- [ ] 运行 `node --test tests/scheduler.test.mjs` 确认失败后实现 scheduler，再运行两测试文件通过。记录完成，不自动提交。

## Task 2 · 可中断回放状态

**Interfaces:** createPlayback(events):{index,playing,elapsed,events}；stepPlayback(state):state、tickPlayback(state,dt,{hidden=false,reducedMotion=false}={}):state、resetPlayback(state,events=state.events):state。每 0.65 秒前进一个事件；dt 上限 0.05，非有限值当零；完成即停止。

- [ ] 写失败测试：单步只推进一事件、结尾不越界、reset/换日志 index=0 且 playing=false；播放结束停止。
- [ ] 写失败测试：后台或 reducedMotion 立即停止且 elapsed=0；120 秒 delta 不补播；新日志不能残留旧事件；输入不变异。
- [ ] 运行 `node --test tests/playback.test.mjs` 观察失败，实现接口，再运行通过。除事件日志不可变共享外，返回新状态。

## Task 3 · 五步界面与三维桥接

**Interface:** createTeachingUI({container,onStation,reducedMotion}):{tick(dt),pause(),setReducedMotion(value),dispose()}。container 为固定 DOM 容器，onStation(index) 使用 main.js 现有 choose。控制器拥有 lesson、strategy、reverse、playback；不直接设置模型或相机坐标。

- [ ] 增加“开始五步教学 / 返回自由观察”原生按钮和独立教学区；自由观察默认显示现有四站点。教学前四步保留整机场景；最后一步提供“看节点/看板卡/看芯片”按钮调用 onStation(1/2/3)。
- [ ] 树图用 SVG 及文字说明表现 MAX/MIN、叶分值、当前访问、已访问及被剪枝状态；未访问叶不显示为评估完成。文字列表给出当前事件与结果，无需仅依赖颜色理解。
- [ ] 第 2/3 步可单步、播放/暂停、重来；第 3 步切换 minimax/alpha-beta 与顺序时重建日志并停播。比较面板来自同输入的两次真实运行，并显示当前事件进度及最终统计，不将最终统计误写成当前已完成数量。
- [ ] 第 4 步使用真实根子任务成本与 scheduleTasks，1/4/8 选择器、任务条与空闲工作者文字。所有时间标注“逻辑调度单位，非真实测速”；显式说明两个独立子树任务不共享剪枝界限。
- [ ] main.js 创建一次控制器，唯一 frame 中调用 tick；visibilitychange 调 pause，matchMedia 改变调 setReducedMotion；退出教学立即 pause；pagehide 调 dispose。按钮事件在 dispose 移除，切模式不重新建渲染器。
- [ ] 错误输入呈现错误说明与重试入口，不复用旧结果。窄屏树图 viewBox 自适应，按钮可换行，文字可读；减少动态效果隐藏/禁用自动播放并说明原因，单步可用。
- [ ] 运行 `npm.cmd run build`、`npm.cmd test`、`npm.cmd run validate`；全部通过后进入浏览器检查。
