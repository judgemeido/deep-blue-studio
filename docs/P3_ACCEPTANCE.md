# P3 可执行教学审阅版 · 2026-10-17

## 实现

新增五步教学模式，默认仍为自由观察。五步是接到棋局、展开搜索、理解剪枝、分派计算、进入芯片。教学使用同一个渲染器和页面唯一动画循环；最后一步调用既有站点命令，不修改 P2 模型、朝向或光影实现。

纯模块提供：固定 15 节点/8 叶树、Minimax/Alpha-Beta、不可变事件日志、确定性调度、可中断回放。叶评分为给定值，不来自棋盘引擎。原顺序完整搜索访问 15 节点/评估 8 叶；剪枝访问 11 节点/评估 5 叶；两者根值 5、根选择 L。反序后剪枝变为 14 节点/7 叶，说明收益依赖顺序。

左右根子树作为两个成本均为 7 的独立全搜索任务，1 个工作者用 14 逻辑单位，4/8 工作者用 7 单位，分别空闲 2/6 个工作者。逻辑时间不是真实测速，也不是深蓝性能。调度任务成本只取访问节点数，不使用这些独立子任务的根值做主树结论。

## 自动证据

新增测试先在模块缺失时运行失败，再实现通过。当前共 28 项测试，含 100 棵种子树两策略结果交叉比较、手算固定结果、负值/平分、输入拒绝、日志计数/剪枝条件、调度唯一性、回放换日志/后台/减少动态效果。既有板卡朝向、放大空间、光影连续性及 HTTP 测试保留。

额外本地自查：教学重绘时使用独立 AbortController 清理旧按钮监听器，保持同名按钮焦点；未增加第二个 requestAnimationFrame。错误结果显示说明和重试入口。未自动提交、推送或部署。

- 第五步“看板卡”调用三维导航，退出教学后自由导航恢复且目标回整机。

## 待验收与边界

未完成真实后台停留、系统减少动态效果切换、全程自动播放到剪枝的浏览器验收、真机触摸/性能、全部历史 P1/P2 待办。完整五步序列并非逐步所有按钮都实测。P2 动画实现本轮未改动，自动回归通过，但不能替代全路径动态视觉复查。

本轮 render 按整个教学面板重建：保证旧监听器释放与同名按钮焦点恢复，但高级 details 展开态会在事件推进时重置，后续可局部更新优化。SVG 在手机上缩小，另有叶分数字面列表和事件文字辅助阅读。当前仅固定树及反序，不实现完整象棋引擎、历史棋局或 P4 芯片精化。

## 单屏布局修正
教学面板由 main 下方移入右侧列，替换自由说明栏；页面使用 100dvh 四行布局。手机模型/说明切换，第五步看硬件后自动切模型。史料和高级界限 details 展开为可关闭浮层。浏览器 DOM 实测：1366×768 页面高768，教学面板 client/scroll=627/627；1280×720 页面高720，面板601/601；390×844 页面高844，面板715/715，下一步按钮底部788。核心教学无需页面或面板滚动。极矮窗口和大字号仍保留面板 overflow:auto 以免内容不可达，不承诺任意尺寸全部同屏。截图 single-screen-desktop.png / single-screen-mobile.png。
