# P4 微观分工审阅版 · 2026-10-17

## 本轮范围

用户确认三项增强：板卡细节、四功能区可选及出处边界。本轮保持单屏布局和 P2/P3 转场/算法不变。两卡仍各 8 颗象棋芯片；新增少量原创器件与金色走线，全部为教学重建，不代表历史 PCB。

芯片放大层四区域与按钮对应：着法生成、局面评估、搜索控制、走法栈与重复检测。支持按钮/键盘及模型射线拾取；拖动超过 5px 不作为点击，过渡终态前不允许拾取或选功能。选择后模型发光高亮，面板显示输入、处理、输出、抽象示例及来源定位。抽象示例不是完整棋类引擎计算，也不是历史日志。置换表明确属于软件搜索层。

## 自动检查
