# P6 芯片微观模型规格

## 视觉责任

| 层 | 画面责任 | 页面边界 | 状态 |
| --- | --- | --- | --- |
| 封装盖 / 侧壁 | 建立可拆开的封装体积与观看尺度 | 封装型号、尺寸和丝印未核实 | schematic |
| 基板 / 焊盘 | 说明芯片与板卡之间的承载和连接关系 | 不是历史服务图 | schematic |
| 裸片 | 提供公开近摄能支持的轮廓和表面质感 | 功能区不等于真实版图 | teaching-reconstruction |
| 键合线 | 表达封装到裸片的教学连接关系 | 数量、路径、针脚编号未核实 | schematic |
| 引脚 | 表达封装边界和方向 | 不声明真实针脚数量或电气功能 | schematic |
| 功能覆盖层 | 让观众点击着法生成、局面评估、搜索控制、走法栈与重复检测 | 来自功能框图的解释层，不是裸片照片解析 | teaching-reconstruction |

## 固定文案

- 芯片内部：教学重建，非历史版图
- 公开资料支持裸片轮廓与功能关系；封装尺寸、丝印、引脚编号和内部布线仍待核实
- 置换表属于软件搜索层，不是这里的硬件功能区

## 交互规则

开盖和剖面改变观看状态；热点和信号追踪只改变教学覆盖层。任何组合都可通过“复位微观视图”回到闭盖、组装、无热点、信号空闲。进入芯片层只精化一颗选中芯片，其余十五颗保留低模，以维持 2 柜 / 30 节点 / 2 卡 / 8 芯片 / 480 颗的展示口径。
