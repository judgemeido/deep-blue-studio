# P1 原型实现与验收记录

日期：2026-10-17。状态：**可运行审阅版，完整 P1 验收仍有待办**。用户确认了设计与直接执行计划；未替用户批准 P0 的 D01–D05，也未进入 P2。

## 实现

- 独立 /prototype/ 入口，保留 P0 四页与资料数据。
- 本地 Three.js 程序化双柜、30 个教学节点；选中节点 1 CPU、2 卡、16 芯片；逻辑总量 480。
- 有序可逆运动：门让位、教学断连、节点抽出、盖板抬升后侧移、卡先拔出后转向、独立放大功能层。
- 统一绝对进度驱动姿态与镜头；前后步、直接选择、复位、四方向观察、OrbitControls、键盘按钮。
- reduced-motion、后台恢复时间戳重置、尺寸观察、页面卸载释放、WebGL 初始化/上下文丢失提示已实现。

## 自动检查

11 项 Node 测试：状态反向/最新目标、100 次复位、时间差钳制、减少动态同终态、非有限输入、配置、幂等矩阵与释放、301 点包围盒采样、碰撞敏感性、相机连续性、窄屏镜头、相邻槽位、HTTP 资源与越界防护。

空间检查仅覆盖门/抽出节点、盖板/两卡、两卡之间及初态相邻槽位；未声称验证全部机械实体。原始所选节点高度超过 0.225 槽距，在失败测试暴露后，将其 Y 缩放为 0.5。柜体总高约 3.94 显示单位，均非实测。

构建、原有 validate 和 Node 测试的最终结果见本轮工具输出与 P1_EVIDENCE.json。
