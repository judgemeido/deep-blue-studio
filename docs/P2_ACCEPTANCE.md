# P2 宏观视觉审阅版 · 2026-10-17

用户确认“1997 工业档案馆”短设计后，在现有 P1 场景上精化，没有重写状态/运动架构。

## 交付

- 黑色机柜使用圆角几何、确定性程序化喷涂粗糙度和实例化真实开孔网格门；保留原有铰链与运动路径。
- 加入中性环境反射、暖主光、冷轮廓光、正面补光、落地阴影及深炭灰展台。
- 原创棋桌、64 格棋盘、32 枚棋子、无品牌 CRT 与键盘；采用开局摆法，不是比赛棋局复刻。细节为场景重建，不代表历史品牌或摆位。
- 道具整体位于 x>2.1 的右侧区域，避开左柜门及选中节点运动通道；progress>=1.2 隐藏，复位恢复。为避免渲染管线改造，本轮使用阶段隐藏而非透明淡出。
- 首屏标题“一步棋，背后的机器。”，保留资料与原型双入口及历史边界。

## 检查与范围

新增测试先见失败再实现：棋盘/棋子数量与道具通道、道具近景隐藏及恢复、门尺寸与实例网格、程序化纹理确定性。既有配置、空间采样、反向/复位、相机与 HTTP 测试继续运行，共 14 项。

纹理完全代码生成，环境为 Three.js RoomEnvironment，不下载照片、模型或 HDRI。纹理和环境贴图纳入释放。未增加高成本后处理或商标；未实现 P3 搜索算法及 P4 芯片精化。

浏览器检查范围与截图见 evidence/p2/。构建、validate、测试以本轮最终命令输出为准。P1 中记录的完整三视图、故障注入、动态偏好及真机性能待办继续存在；P2 是视觉审阅版，不声称全部最终验收通过。

## 已知边界

网孔形态、桌椅布局和 CRT 均为原创教学重建；未添加无出处的顶部编号。机柜内部节点仍使用教学比例，不能据图推断真实机箱厚度。实时阴影当前固定 2048 档，真实手机 GPU 开销尚未测量。黑色层次与首屏构图需要用户视觉审阅后才能定稿。

本轮浏览器实际检查：1440×1000 首屏、板卡近景（道具已隐藏）、复位道具恢复；390×844 首屏完整容纳双柜与棋桌，进入节点按钮可用。抽查控制台 warn/error 为空。截图：desktop.png、card.png、mobile.png。窄屏采用纵向滚动，不承诺首屏同屏显示全部说明。

## 芯片过渡修正
原来 progress=6 才硬切芯片场景，现改为最后一段约 2 秒：先推近板卡选中芯片，同位置/朝向接续放大示意，周围实体渐隐，功能块在后半段逐步显现。反向沿同一绝对进度恢复，reduced-motion 仍直接终态。相机允许小于 2 显示单位的微距，最小距离改为 0.4。新增连续放大与段时长回归测试，共 16 项。

## 放大穿模修正
回归测试复现 progress=5.005 时放大封装与可见硬件包围盒相交。修改为先抬离板卡、周围实体在前 30% 退场、40% 后才放大；微观示意在抬离后显现。物理与微观材质保留深度写入，防止透明表面穿透。新增 200 点可见实体相交及透视相机安全距离采样，17 项测试通过。包围盒为保守检查，并非全视角像素级证明。

## 板卡旋转与放大阴影修正
回归测试确认非均匀缩放的 node 父级导致板卡旋转失真。将选中卡 attach 到未缩放的 physical，保持初态世界矩阵，并显式同步节点 Z 抽出和实际 Y 抬升；绕卡中心作刚体旋转。新增中心不位移/边长不变化测试。微观示意禁用投影和自阴影，避免微小比例与固定 shadow normalBias 的不匹配；淡出物理部件不再保留实心投影。新路径重新通过 200 点微观间隔检查，抬升距离调整为 0.65 显示单位。19 项测试通过。

## 板卡正面展示与连续光影
板卡终态改为根据默认透视镜头计算面向四元数，而非固定 Z 轴角度，组件面法向与镜头方向 dot>0.9999；相机目标对齐板卡中心。放大目标改为根据同一朝向计算选中芯片位置，不再使用过期固定坐标。投影强度在过渡开始连续退到零后才移除投影对象；地面透明度连续退场，避免 p=6 硬隐藏；保持固定光源与曝光。新增朝向及 1000 点阴影/地面连续性测试，共 21 项通过。浏览器本轮可加载并进入板卡路径，但自动化截图/点击出现节点定位错误，不能声称完整动态光影已视觉验收。
